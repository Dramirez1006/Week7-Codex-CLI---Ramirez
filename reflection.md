# Reflection on Using Codex CLI

Using Codex CLI for my Week 7 assignment was a new experience. I was surprised by how quickly it completed my requests. It generated R scripts, performed the analyses I asked for, and created files in my repository without me having to write the code myself. I could focus on the question I wanted to answer and review the results as the work progressed.

At first, I found Codex confusing because I was directing the assignment instead of actively editing the files myself. It took some time to understand how that process worked. As I continued to give instructions, review the results, and ask for changes, I became more comfortable guiding the work. I learned that my instructions needed to be specific and direct. If I left details out, Codex could produce something that technically worked but did not match what I had in mind.

My prompts developed over the course of the assignment. I started by asking Codex to inspect the Ames housing dataset and identify the relevant columns before beginning any analysis. After reviewing that information, I asked it to examine how lot area and sale price were related across neighborhoods. Then I asked for summary tables and visualizations, and later for written findings and updates to my README. This step-by-step approach helped me review the data and results before moving on.

One challenge was interpreting the original scatterplot. It showed the relationship between lot area and sale price for all 28 neighborhoods, with a separate panel for each one. Although it answered my original question, I found the many panels difficult to compare. I asked Codex to create a horizontal bar chart of the neighborhood correlations instead. The bar chart made it easier for me, and for someone seeing the results from the outside, to compare which neighborhoods had stronger, weaker, or negative relationships. We also identified neighborhoods with small sample sizes so their correlations would be read cautiously.

If I completed this assignment again, I would plan my prompts with more detail from the beginning. I would state the exact output I want, how it should be organized, what should be included in a visualization, and any limits on changing files or observations. I would also keep reviewing each step before moving to the next. My experience showed me that Codex can do a lot of the coding and analysis quickly, while clear instructions and careful review help make sure the results answer the question I actually meant to ask.
